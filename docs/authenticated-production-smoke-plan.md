## Global Rules

- Capture a production proof record using `docs/templates/production-proof-record.md` for each app.
- Stop immediately on wrong commit, missing approval, unexpected mutation, auth bypass, cross-workspace access, provider-cost call, or billing mutation.
- Do not complete checkout, create subscriptions, alter Stripe objects, run migrations, or rotate secrets.
- Do not treat local screenshots, local tests, or documentation as production workflow proof.
