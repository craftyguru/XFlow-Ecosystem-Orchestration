# Six-App Ecosystem Case Studies

These case studies cover the core ecosystem only: XFlow, Verixet, Rataify, AudAiX, Crevux, and WordGeni.

The case studies are written for recruiter, investor, and developer review. They use current repo docs, app READMEs, architecture notes, verification notes, and Phase 7.5 local screenshot assets. They do not claim public deployment, customer traction, or live production status unless separately verified.
